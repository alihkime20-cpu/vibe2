# VIBE

تطبيق تواصل اجتماعي مبني على **Expo وReact Native**. هذه النسخة تمثل الهيكل الأولي المنقول من مشروع Expo Snack، مع فصل الشاشات والمكونات والخدمات والثوابت تمهيدًا لربط قاعدة البيانات لاحقًا.

## التشغيل

ثبّت Node.js وExpo CLI، ثم نفّذ الأوامر الآتية داخل مجلد المشروع:

```bash
npm install
npx expo start
```

بعد تشغيل المشروع، يمكن فتحه على Android عبر Expo Go أو المحاكي المناسب.

## البنية

```text
App.js
assets/
components/
screens/
services/
constants/
```

## الحالة الحالية

تم نقل الملفات الموجودة في Expo Snack إلى هذا المستودع. بعض ملفات الشاشات كانت فارغة في مصدر Snack، ولذلك بقيت كملفات هيكلية تمهيدًا لتنفيذها تدريجيًا:

```text
screens/LoginScreen.js
screens/NotificationsScreen.js
screens/ProfileScreen.js
screens/SearchScreen.js
screens/SettingsScreen.js
screens/UploadScreen.js
screens/VideoEditorScreen.js
```

البيانات والخدمات الحالية تجريبية، ولا توجد قاعدة بيانات أو مصادقة حقيقية في هذه المرحلة. يجب عدم وضع مفاتيح سرية داخل التطبيق. ستتم إضافة الواجهة الخلفية وربط قاعدة البيانات في مرحلة مستقلة.

## الخطة التالية

تتمثل الخطوة التالية في ربط `App.js` بالشاشات المنفصلة، ثم تنفيذ الشاشات الفارغة واحدة تلو الأخرى مع حالات التحميل والفراغ والخطأ، وبعد ذلك إضافة التنقل وإدارة الحالة وربط الخدمات الخلفية.
