# World Encyclopedia

منصة موسوعية عالمية متعددة اللغات، أُعيد بناء هذا المستودع لها من الصفر بدل تطبيق VIBE الجوال السابق. النسخة الحالية تقدّم واجهة عربية أولى قابلة للتوسع مع مسارات `/ar` و`/en`، وتصميمًا متجاوبًا، وبنية خلفية جاهزة للمصادقة وقاعدة البيانات.

## التقنية الحالية

يعتمد المشروع على React 19 وVite وTypeScript وTailwind CSS 4 وExpress وtRPC وDrizzle ORM. تم الإبقاء على بنية القالب full-stack المتصلة بخدمات Manus، بما في ذلك المصادقة عبر OAuth وقاعدة البيانات وطبقة التخزين. يستخدم القالب الحالي MySQL/TiDB عبر Drizzle، وليس PostgreSQL؛ وهذا قرار توافق مع بيئة المشروع الحالية ويمكن تغييره لاحقًا ضمن ترحيل مخطط مُراجع.

## ما تم تنفيذه

تتضمن الصفحة الرئيسية رأسًا متجاوبًا، تبديلًا أوليًا للغة، بحثًا تفاعليًا، أبواب المعرفة، بطاقات الشخصيات البارزة، خطًا زمنيًا، أحدث المقالات، وواجهة عربية RTL بهوية لونية هادئة. أضيفت أيضًا جداول `categories` و`encyclopediaEntries` إلى مخطط Drizzle مع حالات المسودة والنشر والأرشفة، وتضمين حقول عربية وإنجليزية لدعم التوسع متعدد اللغات.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

للفحص والبناء والاختبارات:

```bash
pnpm check
pnpm build
pnpm test
```

## الاتجاه التالي

الخطوة التالية هي توليد migration للمخطط وتطبيقها على قاعدة البيانات، ثم إضافة إجراءات tRPC للبحث والصفحات الموسوعية والتصنيفات، وبعدها بناء صفحات التفاصيل ولوحة المساهمات والصلاحيات. لا توجد بيانات مستخدمين أو تقييمات أو مراجعات مصطنعة في المشروع.
